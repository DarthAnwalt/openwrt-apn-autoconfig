# What may be published, and nothing else.
#
# One path prefix per line. A file is publishable only if it is, or lives
# under, an entry here. Everything else stays in the private repository --
# development documents, work-item packets, hardware records, contracts, test
# suites and private build tooling. The one exception is the provider-data
# workflow below: its public-source inputs, generator, checks and package-only
# builder are published because that package is maintained in public.
#
# This is a security boundary: what goes out is what a user, a licence or the
# isolated public provider pipeline needs, not the development record.
#
# Adding a line here is a decision to publish. It is not a formality: run
# `sh scripts/check-public-safe.sh` afterwards, because a path being allowed
# says nothing about what is inside it.
